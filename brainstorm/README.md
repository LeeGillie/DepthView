# Brainstorming

Ideas that have been thought through but not started as part of DepthView proper. Each
one gets its own folder and is written to stand alone, so a link to that folder can be
shared on its own.

Nothing here is a supported feature. Some folders hold a rough prototype; those are
labelled as prototypes and may change or disappear. Discussion and corrections are welcome.
Open an issue and name the folder in the title.

| Idea | What it's about | Status |
|---|---|---|
| [stripfocus](stripfocus/) | Keeping a laser in focus on curved or irregular parts (belt buckles, flasks) on a flat-bed galvo, by describing the surface and splitting the job into focus zones | Researched; working browser prototype for smooth one-direction curves |

## How a folder is laid out

- `README.md`: the problem, the idea, current status, and how to try anything that exists.
- Supporting notes: research with sources, design reasoning, and open questions.
- `prototype/`, if present: throwaway code that proves a point. It is not the eventual
  implementation.

When an idea graduates into DepthView, its folder stays as the record of how it was
reasoned, with a note pointing at the real code.
