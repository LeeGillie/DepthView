# Acknowledgements

Software licences live in [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md). This file is for
the people whose work shaped DepthView without being a dependency.

## Test material

A tool that inspects depth maps is only as good as the depth maps it has been pointed at, and
files made deliberately as test cases are the easy ones. Real work — made by someone solving a
real problem, not demonstrating a defect — is what finds the gaps.

**Victor Wolansky** — for the Dolly Parton memorial coin relief, made and
[shared freely](https://www.facebook.com/share/p/1DBNtGvZTS/) with the engraving community.
DepthView was tested against it, and it is a genuine, honest 8-bit map: 4404 × 4404, all 256
levels present, level step 1, no imposter signature anywhere in it.

**None of these files are distributed in this repository.** They belong to the people who made
them. They were used to check DepthView's output against real work, which is a use their
creators did not need to grant and which changes nothing about who owns them. If you want one,
go to its author.

The sample depth maps in [`samples/`](samples/) are generated by `samples/make_samples.py` and
are original to this project.

## Prior art and context

**LightBurn Software** — for the 3D Sliced Image mode DepthView is largely aimed at, and for
documentation candid enough to state where its depth control ends. Several of DepthView's
findings exist specifically because LightBurn's own documentation is honest about the limits.

**The WeCreat Lumos Ultra community** — for working out in public what a 256-layer relief
actually needs from its source image, well before any tool was checking.
